# 페이퍼 그림자 극장 (Paper Shadow Theater)

불 꺼진 흰 종이 상자를 톡 누르면 뒤에서 빛이 켜지고, 그 빛 속에서 동화를 읽어 주다가 마지막에 불이 천천히 꺼지는 **잠자리 동화 앱**. 놀이 모드 없이 **자동 읽어 주기**와 **부모와 함께 읽기** 두 가지로 보며, 앱의 모든 그림은 빛 상자 방식(흰 종이 층 + 앱이 입히는 빛)이다.
이야기와 목소리는 형제 프로젝트 [톡톡 동화극장(paper-tale-theater)](https://github.com/DH-KIM-hug/paper-tale-theater)의 읽어 주기 대본·녹음을 그대로 쓰고, 그림은 모두 빛 상자 방식으로 새로 만든다.

지금은 기획 단계입니다.

- [`PLAN.md`](PLAN.md): 앱 기획서 — 두 읽기 모드, 화면, 무대 체계, 동화 고르기, 기술 구성, 판단 필요 항목, 진행 순서
- [`docs/REUSE.md`](docs/REUSE.md): 동화극장에서 가져오는 대본·녹음·재생 엔진과 동기화 방법
- [`docs/STORY_EDIT.md`](docs/STORY_EDIT.md): 잠자리 대본 다듬기 — 놀이에서 온 사족 빼기, 첫 출시 4편의 줄별 결정
- [`docs/STAGE_FORMAT.md`](docs/STAGE_FORMAT.md): 장면별 상자·빛·종이 인형을 적는 `stage.json` 형식과 「토끼와 거북이」 예시

## 저작권
오픈소스가 아닙니다. 그림·음성·대본·캐릭터·코드의 저작권은 저작자에게 있으며, 허락 없는 복제·재배포·상업적 사용을 금지합니다. 대본과 녹음은 톡톡 동화극장의 것을 같은 저작자가 가져와 씁니다.
