# 쿨쿨 그림자극장

뒤에서 빛이 비치는 종이 상자 속에서 동화를 읽어 주다가 마지막에 불이 천천히 꺼지는 **잠자리 동화 앱**. 놀이 모드 없이 **자동 읽어 주기**와 **부모와 함께 읽기** 두 가지로 보며, 앱의 모든 그림은 빛 상자 방식(흰 종이 층 + 앱이 입히는 빛)이다.
이야기와 목소리는 형제 프로젝트 [톡톡 동화극장(paper-tale-theater)](https://github.com/DH-KIM-hug/paper-tale-theater)의 읽어 주기 대본·녹음을 그대로 쓰고, 그림은 모두 빛 상자 방식으로 새로 만든다.

## 실행

**웹에서 바로 보기:** https://dh-kim-hug.github.io/tale-night/ (`DH-KIM-hug/main` 브랜치를 올리면 바뀐다)

```bash
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765 열기
```

빌드 없는 정적 웹입니다(동화극장과 같은 방식, 나중에 Capacitor 로 감쌉니다).

## 지금 들어 있는 것 (첫 출시 4편 + 시범 1편)

| 동화 | 장면 | 줄 | 길이 |
|---|---|---|---|
| 토끼와 거북이 | 9 | 53 | 약 5분 |
| 아기 돼지 삼형제(그림 시범, 첫 출시 목록 밖) | 10 | 53 | 약 5분 |
| 해와 바람 | 7 | 46 | 약 4분 |
| 미운 아기 오리 | 10 | 69 | 약 7분 |
| 커다란 순무 | 10 | 54 | 약 5분 |

- **자동으로 읽어 줘요**: 녹음이 읽고, 장면마다 빛 색·종이 인형이 바뀌고, 끝나면 빛이 8초에 걸쳐 꺼진다. '아무 이야기나' 이어 듣기(편 수는 보호자 설정), 멈춤·건너뛰기, 잠금 화면 조작, 60초 뒤 어두운 덮개, 잠드는 화면.
- **함께 읽어요**: 글 판에 지금 줄만 밝게, → / 무대 오른쪽 끝 톡으로 넘김, ← 앞 줄(무대도 그 줄 상태로 되돌아감), 읽는 동안 화면 꺼짐 막기, 이어 읽기.
- **보호자 설정**(홈의 달 1초 꾹): 편 수, 자막, 빛 세기, 움직임 줄이기, 글자 크기, 인물 대사만 녹음, 무대 어디든 톡으로 넘기기.
- **그림은 2편만 있다.** 토끼와 거북이·아기 돼지 삼형제는 전 장면에 그림이 있고, 나머지 3편과 스플래시는 아직 없어 빛만 보인다. 목록과 규칙: [`docs/ART_LIST.md`](docs/ART_LIST.md), 만드는 도구: `tools/gen_art.py`.

## 도구

| 명령 | 하는 일 |
|---|---|
| `node tools/sync_from_theater.mjs <동화극장 경로>` | 대본·녹음 가져오기 + `edit.json` 덮기 + 꼬리 자르기 |
| `node tools/art_list.mjs` | 그림 있는 것·없는 것 |
| `node tools/check_stage.mjs` | 대본·무대·그림·녹음 맞물림 점검 |
| `python3 tools/rec_night.py <동화극장 경로> [--dry]` | 새 줄 녹음(ElevenLabs 키 필요) |
| `tools/dev/scenes.html?id=rabbit` | 장면마다 불 켠 모습 한눈에 보기 |
