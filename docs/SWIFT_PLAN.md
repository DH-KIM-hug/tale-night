# Swift 앱 기획서 (초안, 2026-11-05)

> 앱은 처음부터 Swift(SwiftUI)로 만든다. 지금 웹은 시범판이고, 그림·대본·무대(`content/<id>/stage.json`)·녹음은 그대로 옮겨 쓴다. 제품 사실은 `PRODUCT.md`, 웹 시범판의 화면 설명은 `PLAN.md` §4. 이 문서는 사용자 확인 전이다.

## 1. 누가, 언제

- 보호자와 3~7세 아이, 잠들기 전 침대. 화면 바탕은 흰색이고 그림이 주인공이다.
- 보호자는 두 번 톡으로 시작한다: 동화 고르기 → 읽어 줘요 또는 함께 읽어요. 그 뒤로 아이가 할 일은 없다.
- 성공: 한 편(또는 이어 듣기 몇 편)이 끝나고 빛이 천천히 꺼지면 화면이 조용히 멈춘다.

## 2. 화면 흐름 (웹 시범판의 뼈대를 유지)

| 화면 | 하는 일 | iOS 방식 |
|---|---|---|
| 스플래시 | 앱 아이콘 그림이 잠깐 떴다 홈으로 | Launch Screen + 첫 화면 페이드 |
| 홈 | 큰 아치 창문에 고른 동화, 아래 작은 창문 줄, 「읽어 줘요」·「함께 읽어요」 | 한 화면. 탭바·큰 제목 없음(섹션이 하나뿐). 아이패드 가로는 창문 왼쪽, 글과 단추 오른쪽 |
| 자동 읽어 주기 | 무대가 화면을 다 씀. 멈춤·건너뛰기는 톡하면 나타났다 물러남 | 전체 화면 커버(`fullScreenCover`). 잠금 화면 조작(Now Playing), 화면이 꺼져도 끝까지 |
| 함께 읽기 | 위는 무대, 아래 띠에 지금 대사 묶음. → 다음, ← 앞 | 같은 전체 화면 커버. 읽는 동안 화면 꺼짐 막기 |
| 잠드는 화면 | 빛이 꺼진 뒤 달과 「잘 자요」, 「집으로」 | 커버 안의 마지막 상태 |
| 보호자 설정 | 달을 1초 꾹 → 편 수, 자막, 빛 세기, 움직임 줄이기, 글자 크기, 인물 대사 녹음, 어디든 톡 | 시트(`sheet`) + 기본 컨트롤(Picker 세그먼트, Toggle), 묶인 목록 |

- 그림 위에 뜨는 것(집 단추, 제목과 장면 점, 장면 이름)은 모두 같은 어두운 알약 하나로(웹에서 정리한 방식).
- 아이콘은 SF Symbols. 단추는 44pt 이상. UI 글자는 시스템 글꼴과 Dynamic Type, 함께 읽기 대사만 보호자 설정의 글자 크기를 따른다.
- 왼쪽 끝을 밀어 뒤로 가기는 막지 않는다. 다만 재생 중 실수로 나가지 않게, 재생 화면은 아래로 쓸어 닫기를 막고 집 단추로만 나간다.

## 3. 무대 엔진 (stage.json → SwiftUI)

- 무대는 `ZStack` 의 층 그림. 화면 비율로 `tab`(3:2) · `land`(2.17:1) · `port`(0.46:1) 중 하나를 고르고, 짧은 쪽이 남으면 검정.
- 움직이는 것: 구름 흐름(drift), 가지 흔들림(breeze, sway), 등불 살랑(swing), 불 깜빡임(flicker), 나비, 반딧불, 누르면 피어오르는 반딧불. 인물은 자리를 옮기지 않고 자세만 바뀌며 나타나고 사라진다(0.7초 페이드).
- 대본 줄마다 무대 상태를 미리 계산(웹 `engine/story.js` 와 같은 규칙: `cues` 의 동사, 장면 가운데 `box:` 바꾸기, 인물 모습이 바뀌는 줄에서 대사 묶음 나누기).
- 소리: `AVAudioPlayer` 로 줄 녹음을 차례로, 줄 사이 쉼 700ms, 장면 끝 1500ms. 잠금 화면 조작과 백그라운드 재생.
- 움직임 줄이기: 시스템 설정(Reduce Motion)과 보호자 설정 둘 다 따른다.

## 4. 장면 그림 (빛 상자가 기반)

모든 장면 그림은 **빛 상자**다. 2026-11-05 시험에서 다음 규칙을 지시문에 넣었을 때 빛 상자처럼 나왔다(`tools/art_jobs/v2_lightbox_test.json`).

- 장면은 앞뒤로 겹친 **납작한 종이 층** 몇 장뿐. 뒤에서 빛이 비쳐 먼 층이 가장 밝고, 가까운 층일수록 어둡다. 맨 앞은 거의 까만 그림자.
- 원근으로 그린 방, 그려 넣은 빛줄기, 소용돌이, 눈송이·나뭇잎 같은 입자, 층 안의 선·무늬를 넣지 않는다. 움직이는 것은 따로 만든 조각으로 앱이 움직인다.
- 우리나라 것: 초가, 한지 창살 창, 아궁이와 가마솥, 장독, 장승. 흔들의자·무쇠 난로·서양 헛간·수레는 쓰지 않는다.
- 호박색은 아궁이 입구, 창문, 등불처럼 작은 곳만. 방 전체를 호박색으로 칠하지 않는다.
- 인물이 서는 가운데는 뒤가 옅은 빛으로 비어 있어, 까만 인형의 윤곽이 보인다.
- 동화마다 **처음은 옅고 맑게, 끝으로 갈수록 깊게**. 마지막 장면은 그 동화에서 가장 어둡다.

동화별 장소(`docs/SCENE_PLAN.md` 의 표)는 그대로 쓰되, 끝이 밝았던 두 곳을 고친다.

| 동화 | 고칠 곳 | 고친 뒤 |
|---|---|---|
| 해와 바람 | R08 「사이좋게」가 낮 하늘 | 해가 지는 저녁 하늘, 첫 별. 해와 바람이 나란히 |
| 미운 아기 오리 | R11 「백조 가족」이 봄 새벽 | 봄 호수의 저녁, 달이 뜬 물 위에 백조들 |

만드는 순서: 상자 하나를 태블릿 시안 → 가로·세로 → 층 → 앱에 넣어 화면 확인까지 끝내고 다음 상자로 넘어간다. 한꺼번에 여러 묶음을 돌리지 않는다.

## 5. 상태

- 그림이 아직 없는 편: 홈 작은 창문이 닫힌 창문으로 보이고 고를 수 없다.
- 처음 실행: 날짜로 고른 한 편이 큰 창문에. 읽던 편이 있으면 그 편과 「이어 읽어요」.
- 재생 중 멈춤·전화·이어폰 빠짐: 멈추고, 다시 톡하면 그 줄부터.
- 이어 듣기 끝, 함께 읽기 끝: 빛이 8초에 걸쳐 꺼지고 잠드는 화면.

## 6. 범위 (이번 SwiftUI 시안)

1. Xcode 프로젝트를 만들고, 그림·대본·녹음을 앱 묶음으로 복사하는 스크립트.
2. 무대 엔진과 **토끼와 거북이 자동 읽어 주기**(완성된 그림이 있는 유일한 편) 한 편 끝까지.
3. 홈(큰 창문 + 작은 창문 줄)과 함께 읽기, 잠드는 화면, 보호자 설정 시트.
4. 아이패드 가로와 아이폰 가로·세로 시뮬레이터에서 화면 확인.

이번에 하지 않는 것: 구매·잠금, 앱스토어 제출, 나머지 동화 그림(4절 순서대로 따로 진행).
