# 잠자리 대본 다듬기 — 놀이에서 온 사족 덜어내기

> 2026-11-01 사용자 질문: "읽어 주기 모드에서 과한 놀이 부분은 아예 빼든지, 연결 대사·내레이션을 새로 녹음하든지. 예를 들면 토끼와 거북이의 부엉이 우체부 장면. 이것들은 놀이 모드용을 읽어 주기로 바꾼 거라 동화의 사족이다."
> 근거: 동화극장 `tales/<id>/read_script_el.json` 4편(토끼와 거북이·해와 바람·커다란 순무·미운 아기 오리)을 한 줄씩 읽고 원작 줄거리와 비교했다.

## 0. 결론

- **빼는 것이 기본이다. 새 녹음은 거의 필요 없다.** 4편을 다듬어 보니 빼고 나서 이야기가 끊기는 곳은 **1군데**(커다란 순무 고양이 줄)뿐이고, 새로 녹음할 글자는 **24자**다. 나머지는 빼기만 하거나, 이미 있는 녹음의 꼬리를 자르면 된다(`trim_line.py`, 크레딧 없음).
- 이유
  1. 동화극장 읽어 주기 대본은 "기존 녹음을 글자 그대로 최대한 재사용"(READ_MODE 사용자 결정 1)하려고 **놀이판 장면을 거의 다 살려 둔 것**이다. 그래서 놀이 때문에 생긴 사건이 이야기 안에 남아 있다. 그 사건은 앞뒤 줄과 느슨하게 이어져 있어 빼도 흐름이 상하지 않는다.
  2. 잠자리에는 **짧고 조용한 쪽**이 맞다. 다듬으면 한 편이 약 1~2분 줄어든다(아래 표).
  3. 새 녹음을 많이 하면 목소리·말투가 미묘하게 달라지고, 동화극장과 원본이 갈라진다. 빼기는 원본 녹음을 그대로 쓴다.
  4. 장면이 줄면 빛 상자 그림도 준다(토끼와 거북이: 인형 1종 빠짐).
- **부엉이 우체부 장면(토끼와 거북이 R03 「응원석」)은 통째로 뺀다.** 원작(이솝)에 없고, 놀이판의 '초대장 누르기·친구 부르기'에서 생긴 장면이다. 빼도 다음 장면 첫 줄 "토끼와 거북이는 친구들 앞 출발선에 나란히 섰어요."가 구경하는 친구들을 자연스럽게 데려온다.

| 동화 | 장면 | 줄 | 어림 시간 | 새 녹음 | 꼬리 자르기 |
|---|---|---|---|---|---|
| 토끼와 거북이 | 11 → 9 | 84 → 53 | 6.6 → 4.3분 | 0 | 0 |
| 해와 바람 | 8 → 7 | 62 → 46 | 5.0 → 3.7분 | 0 | 0 |

어림 시간 = 글자 수 ÷ 350자/분(동화극장 READ_MODE §3-6 실측) + 줄 사이 0.7초 + 장면 끝 1.5초. 실제 녹음 길이로 다시 잰다.

## 1. 무엇을 빼나 — 판단 기준

한 줄(또는 한 장면)마다 세 가지를 묻는다.

1. **원작에 있나?** 원작 줄거리의 사건이면 남긴다.
2. **놀이에서 왔나?** 놀이판의 누르기·고르기·세기·연타·위치말·순서 맞추기 때문에 생긴 사건·되짚기·질문이면 뺀다. 예: 초대장 돌리기, 준비 운동(귀 쭉·목 쭉), 장애물 넘기 여러 개, 사진 판정, 금메달, "여섯 그릇, 여섯 명!", "알, 아기, 어린 새, 그리고 백조!", "물에 누가 비쳤을까요?".
3. **잠자리에 보탬이 되나?** 놀이에서 왔어도 **조용하고 잠과 어울리는 짧은 장면**(부엉이 자장가, 토끼의 꿈)은 남길 수 있다. 시끄러운 것(응원 파도, 북과 방울)은 뺀다.

덧붙여 빼는 것
- **장소 다시 말하기 줄**: "텃밭에서 할아버지가 순무 곁에 기다리고 있었어요."처럼 장면 카드가 바뀔 때마다 장소를 다시 알려 주려고 새로 쓴 첫 줄. 빛 상자는 장면이 바뀌어도 상자가 그대로라 다시 말할 필요가 없다. 시간이 흐르는 줄("며칠 뒤…")은 남긴다.
- **빠진 놀이에 대답하는 줄**: "흥, 알았어!"처럼 놀이판에서 아이가 한 일에 대답하는 말.
- **교훈 두 번**: 같은 교훈을 두 번 읽으면 하나만 남긴다. "끝!" 같은 활기찬 맺음은 뺀다(빛이 꺼지는 것이 끝이다).

새로 녹음하는 경우
- 빼고 나서 **앞뒤가 말이 안 될 때만**, 내레이터 목소리로 한 줄. 배역 새 대사는 쓰지 않는다.
- 동화극장 대본 규칙(READ_MODE §3-3)을 그대로: 15~45자, 조작 안내 낱말 없음, 그 동화 `voice_script_el.json` 의 `nar` 목소리.

## 6. 어떻게 적고 만드나

### 6-1. 원본은 고치지 않는다
동화극장 읽어 주기 대본은 동화극장 놀이판 그림 연출(`before/after` 동사)과 맞물려 있어, 거기서 줄을 빼면 동화극장 읽어 주기도 바뀐다. 그래서 **이 레포에 다듬기 파일을 두고**, 동기화 도구가 원본 위에 덮어 `content/<id>/script.json` 을 만든다.

`content/<id>/edit.json`
```json
{
  "tale": "turnip",
  "cut":   { "R04_grandma": [0], "R07_cat": [0, 3, 4], "R10_feast": [0, 5] },
  "match": { "R07_cat#3": "어? 강아지랑 고양이가", "R10_feast#5": "여섯 그릇" },
  "trim":  [],
  "new":   [ { "after": "R07_cat#2", "text": "고양이도 강아지 꼬리를 꼭 잡았어요. 영차!",
               "segs": [["nar", "고양이도 강아지 꼬리를 꼭 잡았어요. 영차!", null, "[warm, storytelling, together]"]] } ],
  "merge": [],
  "card":  {}
}
```
- `cut`: 장면 key → 뺄 줄 번호(원본 기준), 또는 `"*"`(장면 통째로).
- `match`: 줄 번호가 가리키는 원본 글의 앞부분. 동화극장 대본이 바뀌어 번호가 어긋나면 동기화가 멈추고 알린다.
- `trim`: `{ "at": "R01_nest#4", "text": "<자른 뒤 글>" }`. 녹음은 원본 클립의 꼬리를 자른 것.
- `new`: 새 줄. `after` 뒤에 끼운다. `segs` 는 동화극장 대본과 같은 꼴.
- `merge`: `[["R06_shade", "R07_dream"]]` = 뒤 장면 줄을 앞 장면 끝에 붙이고 뒤 장면을 없앤다(카드도 앞 장면 것).
- `card`: 장면 카드 글자 바꾸기(글자만, 녹음 없음).

### 6-2. 자르기·새 녹음 만들기
- 이 레포의 `tools/rec_night.py <동화극장 경로> <id>` 가 동화극장의 `tools/elevenlabs/gen_tale.py`(목소리 생성)와 `trim_line.py`(꼬리 자르기)를 **가져다 불러** `audio/<id>/night_<해시>.mp3` 를 만든다. 목소리는 동화극장 그 동화 `voice_script_el.json` 의 `voices` 그대로, API 키는 `~/.config/elevenlabs/key`(어느 레포에도 두지 않음).
- 동화극장 레포에는 아무것도 쓰지 않는다.
- 4편 합계: 새 녹음 24자(1줄), 꼬리 자르기 2줄.

### 6-3. 함께 읽기에도 같은 대본
부모와 함께 읽기 글 판도 다듬은 대본을 보여 준다. 두 모드가 같은 이야기여야 아이가 헷갈리지 않는다.
