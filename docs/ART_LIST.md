# 그림 목록 — 첫 출시 4편

> 그림은 동화극장처럼 **이미지 생성(ChatGPT·Codex) 후 다듬기**로 만든다. 코드로 그린 그림은 쓰지 않는다(2026-11-01 사용자 결정: SVG 제작 취소).
> 앱은 그림이 없는 층을 비워 둔다(대신 그리지 않는다). 무엇이 있고 없는지: `node tools/art_list.mjs`

## 1. 공통 규칙 (빛 상자 시안과 같음)

- **흰 종이만.** 모든 층·인형은 흰(아주 옅은 크림) 종이 한 색. 색·그라데이션·광택 없음. 빛 색은 앱이 입힌다(PLAN §5-1).
- **배경은 투명(알파).** 종이가 없는 곳은 투명해야 뒤에서 빛이 비친다.
- **빛이 새는 곳은 오린 구멍(투명).** 창문, 잎 사이, 인형의 눈·귀 안쪽·등딱지 무늬. 구멍이 많을수록 불을 켰을 때 예쁘다.
- 동화극장 `DESIGN_SYSTEM.md` 재료 원칙 유지: 가위로 오릴 수 있는 형태, 깨끗한 절단면, 종이 섬유결, 조각 경계에만 얕은 웜 그림자(`#2E241C`). 바깥 그림자는 넣지 않는다(앱이 붙인다). 사물에는 얼굴 없음.
- 꺼진 상태에서는 **그림이 그대로** 보이고, 켜진 상태에서는 그림 모양으로 오린 빛 위에 그림의 종이결이 35% 겹친다. 그래서 종이결·경계 그림자가 살아 있는 그림일수록 좋다.

| 종류 | 크기 | 파일 |
|---|---|---|
| 상자 층(far·mid·near·frame) | 2048×1536 (4:3), WebP 알파 | `art/<동화>/<상자>_<층>.webp` |
| 종이 인형 한 자세 | 1024×1024, 발이 아래 가운데, 오른쪽을 봄 | `art/dolls/<이름>.webp` |
| 무리 인형(오리 넷·백조 셋 등) | 2048×1024 | `art/dolls/<이름>.webp` |
| 스플래시·홈 머리 상자 | 2048×1536 | `art/app/stage_far·stage_mid·stage_near·curtain_frame.webp` |

층마다 차지하는 높이(앞 층일수록 아래만):
- **far** 먼 산·하늘의 구름 — 화면 아래 절반쯤까지, 위쪽은 투명(하늘에 광원이 보여야 함)
- **mid** 언덕·집·나무 — 아래 40% 안팎
- **near** 앞 풀숲·물결 — 아래 15~25%
- **frame** 앞 틀(나무 터널·잎 모서리·커튼·기둥) — 가운데를 크게 비운 틀
- 인형은 mid 와 near 사이에 서고, 발끝은 near 풀숲에 살짝 가려진다. **near 가 인형을 가리지 않게** 가운데 아래를 낮게.

## 4. 앱 그림
- 스플래시·홈 머리 상자: 극장 커튼 틀 + 달밤 언덕·집·나무.
- 앱 아이콘: 위 상자를 앱으로 불 켜 찍어 만든다(그림을 받은 뒤).

## 5. 넣는 법
1. 파일을 위 경로·이름 그대로 `art/` 에 넣는다.
2. `node tools/art_list.mjs` 로 빠진 것 확인, `tools/dev/scenes.html?id=rabbit` 으로 장면마다 불 켠 모습 확인.
3. 인형 크기·자리가 그림과 안 맞으면 `content/<동화>/stage.json` 의 `w`·`x,y` 만 고친다.
